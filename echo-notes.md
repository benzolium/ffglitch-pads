# Эхо движения

## Следующий макет

- Вариант 3: XY управляет параметрами одного выбранного пэда; полоса применения и огибающая параметра разделены.
- Синхронные оригинал и результат: для вертикального видео рядом, для горизонтального друг под другом.
- `pad-library.json` — конфиги для исследования UI, не исполняемый контракт. Диапазоны ручек предложены для PoC; заимствованные эффекты ещё не адаптированы к общему микшеру.

## История

- Первый режим: история векторов движения из исходного потока, по мотивам официального примера FFglitch. История собирается и до включения эффекта.
- История не замыкается через шов лупа.
- Отложенная альтернатива — **Feedback** (рабочее название): Эхо запоминает уже изменённые векторы и использует их на следующих кадрах. Это не повторное кодирование видео и не обычное наследование артефактов через опорные кадры MPEG.
