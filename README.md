# FFglitch Pads

Локальный десктопный PoC в браузере: синхронные оригинал и обработанный
вертикальный луп, четыре пэда и таймлайн. FFglitch пересчитывает превью
после изменения рецепта. Сервер слушает только `127.0.0.1`.

## Запуск

Текущая проверенная конфигурация: macOS Apple Silicon, Python 3,
FFmpeg с `libx264` и FFglitch 0.10.2.

```sh
python3 serve_xy.py
```

Откройте <http://127.0.0.1:8765/portrait.html>. Если порт уже занят
временной копией PoC, остановите её перед запуском этой копии.

Чтобы проверить своё видео, укажите начало в секундах и нажмите
«Открыть видео…». Луп длится 4 секунды; если видео заканчивается
раньше, последний кадр удерживается до конца. Звук в превью отключён.
Файлы до 256 МиБ передаются только процессу на `127.0.0.1`. Исходник
не меняется: временная копия удаляется после подготовки, а рабочие
копии и кэш живут во временной папке процесса до его штатного завершения.

## Подготовка чистого чекаута

Исходное видео, бинарник FFglitch и результаты рендера не хранятся в Git.
Из корня репозитория:

```sh
curl -fL 'https://ffglitch.org/pub/bin/macos-aarch64/ffglitch-0.10.2-macos-aarch64.zip' -o engine.zip
unzip -q engine.zip
curl -fL 'https://videos.pexels.com/video-files/8996518/8996518-hd_1080_1920_30fps.mp4' -o street.mp4
python3 render_portrait.py
./ffglitch-0.10.2-macos-aarch64/ffedit -i portrait/work.avi -f mv -f q_dct -e portrait/texture-source.json
```

Видео: [People Walking on the Street, Pexels](https://www.pexels.com/video/people-walking-on-the-street-8996518/).

## Управление

- `1–4` выбирают пэд; выбор дорожки синхронизирован с пэдом.
- В библиотеке семь эффектов, на пэдах — четыре одновременно.
  Эффект из библиотеки заменяет выбранный слот; уже загруженные эффекты
  можно поменять местами. Настройки и отрезки остаются с эффектом до
  перезагрузки страницы; в сохранённый рецепт входят только активные слоты.
- `←` / `→` перематывают на кадр; пробел — пауза и продолжение.
- `A` добавляет отрезок в позиции воспроизведения, `D` удаляет выбранный.
  Двойной клик добавляет отрезок в свободном месте дорожки.
- Границы можно перетаскивать или задавать в миллисекундах. Отрезки на
  одной дорожке не перекрываются; разные дорожки могут перекрываться.
- «Сохранить рецепт» выгружает параметры готового превью в JSON.

Рецепт версии 1 содержит `pads`: номер слота, идентификатор эффекта,
параметры и отрезки применения в миллисекундах. Номер слота задаёт
клавишу, а не порядок обработки. Пока каждый из семи реализованных
эффектов можно включить в рецепт не больше одного раза.
